# Mars Explorer

Mars Explorer is a keyboard-only interactive website for exploring all of humanity's attempt of ever touching the Martian surface, through a 3D globe.

The site is built around a 3D Mars globe that can be rotated using the arrow keys. There is no cursor-based interaction; the entire experience is designed to be navigated from the keyboard.

## Features

### Interactive Mars Globe

* Rotate the Mars globe using the arrow keys.
* Explore the planet from different angles.
* Rover locations are displayed directly on the globe.

### Keyboard-Only Navigation

The entire website can be used without a mouse or cursor. Keyboard controls are used for navigating the globe, switching between missions, interacting with panels, and moving through mission media.

### Surface Missions

Press `Esc` to enter the mission navigation interface and browse the project's collection of Mars surface missions.

Each mission is associated with its location on Mars, allowing the missions to be explored geographically rather than as a simple list.

### Mission Details

Opening a mission displays a dedicated information panel containing:

* Mission details
* Mission summary
* Mission objective and outcome
* Landing and arrival information
* Selected notable photographs from the mission
* A link to additional information about the mission

### Mission Photography

Mission panels include some of the most notable photographs associated with each mission, providing visual context alongside the mission information.

### Reset Globe View

A reset button is available to return the globe to its default viewing position.

## Controls

| Key            | Action                                            |
| -------------- | ------------------------------------------------- |
| `Arrow Keys`   | Rotate and navigate the Mars globe                |
| `Esc`          | Enter or exit the mission navigation interface    |
| `Left / Right` | Move between missions                             |
| `A / D`        | Move between mission photographs                  |
| `L`            | Focus the external information link               |
| `Esc`          | Return from the mission panel to the mission view |

Controls may change as development continues.
